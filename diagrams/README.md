# Diagrams — Interactive AD Visuals

Self-contained HTML pages built while learning the domain model. Open any of them
directly in a browser (double-click, or `xdg-open <file>.html`). No server needed.

> Content is in Spanish (personal study material); English translation pending.

| File | What it shows |
|------|---------------|
| [`ldap-tree.html`](ldap-tree.html) | The domain as an **LDAP directory tree** — how the forest, domain, OUs and objects nest. |
| [`permissions-model.html`](permissions-model.html) | The **two kinds of power** in AD: access to resources (granted through groups) vs. authority over objects (delegated through OUs). |
| [`ad-explorer.html`](ad-explorer.html) | An **ADUC-style explorer** of the Nordwind domain — browse OUs, users and groups the way the Windows console presents them. |
